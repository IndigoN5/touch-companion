=====================================================
  HOW TO USE THESE TEMPLATES
  NUVABASE - Title 1 School Performance Dashboard
=====================================================

Hello! These templates are for entering your school's
data into the Title 1 Performance Dashboard.

WHAT YOU NEED:
- Microsoft Excel, Google Sheets, or any spreadsheet app
- Your school's student data

-----------------------------------------------------
STEP 1: OPEN THE TEMPLATE
-----------------------------------------------------
- Double-click "student-data-template.csv"
- It will open in Excel or Google Sheets
- You'll see columns with example data

-----------------------------------------------------
STEP 2: DELETE THE EXAMPLE ROWS
-----------------------------------------------------
- The first row (headers) must STAY - do NOT delete it
- Delete rows 2 through 7 (the example students)
- Now you have an empty template ready to fill

-----------------------------------------------------
STEP 3: ENTER YOUR STUDENTS
-----------------------------------------------------
Fill in each column:

  Student Name     = Last name, First name (example: Smith, John)
  Grade            = K, 1, 2, 3, 4, or 5
  Reading Level    = Above Grade, At Grade, Below Grade, or Far Below Grade
  Math Level       = Above Grade, At Grade, Below Grade, or Far Below Grade
  Attendance Rate  = Number from 0 to 100 (example: 94)
  Intervention     = None, Reading Recovery, Math Mastery Lab,
                     After-School Tutoring, Summer Bridge, or Mentoring Program
  Notes            = Any extra info (optional)

-----------------------------------------------------
STEP 4: SAVE THE FILE
-----------------------------------------------------
- In Excel: File > Save As > choose "CSV" format
- In Google Sheets: File > Download > Comma-separated values (.csv)
- Keep the file name ending in .csv

-----------------------------------------------------
STEP 5: UPLOAD TO THE DASHBOARD
-----------------------------------------------------
- Open the dashboard in your web browser
- Click the "Data Entry" tab
- Click the "Upload CSV" button
- Select your saved .csv file
- Your data appears automatically!

-----------------------------------------------------
SAME STEPS FOR PARENT EVENTS
-----------------------------------------------------
Use "parent-events-template.csv" for parent engagement
data. Same process - fill it in, save as CSV, upload.

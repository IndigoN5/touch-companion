User Manual

Everything you need to know about using the Construction Intelligence dashboard. Click any section to expand.

Welcome to the NUVABASE Construction Intelligence dashboard. This tool is designed to give you a comprehensive view of your construction business operations, from bid tracking to compliance management.

Quick Start:

1. Review your Dashboard tab to see key performance indicators at a glance.

2. Check the API Connections tab to connect your live data sources (Procore, SAM.gov, etc.) or continue using demo data.

3. Browse Bid Intelligence to review active and historical bids.

4. Use the ROI Calculator to quantify the value NUVABASE brings to your operations.

5. Generate professional proposals using the TLRW methodology framework.

The dashboard works offline and stores your settings locally in your browser. No internet connection is required after initial load.

The Dashboard tab provides six key performance indicators (KPIs) that summarize your current business state:

Active Bids — the number of bids currently in progress. A green arrow indicates growth from the previous period.

Win Rate — your historical percentage of bids won. This is a critical metric tracked over rolling quarters.

Active Projects — how many projects you are currently executing, along with their combined contract value.

Avg Bid Size — the average dollar value of your submitted bids, with the range showing your market segment.

Compliance Score — a weighted average of your compliance and bonding status. Keep this above 90% to remain bid-eligible.

Pipeline Value — the total dollar value of opportunities you are tracking over the next 90 days.

The bar chart below the KPIs shows your monthly bid volume trend, helping you identify seasonal patterns and capacity planning needs.

The API Connections tab allows you to connect four external data sources:

Procore — enter your Procore API Key and Company ID to sync project data, RFIs, and change orders automatically.

SAM.gov — enter your SAM.gov API Key to access federal contract opportunities and verify entity registrations.

State Procurement Portal — configure your state, portal URL, and credentials to pull state-level bid solicitations.

Dodge Data & Analytics — enter your Dodge API Key to access construction market intelligence and project leads.

When credentials are saved, the status badge changes from yellow "DEMO" to green "LIVE". Credentials are stored only in your browser's local storage and are never transmitted to any server.

If you don't have API access, use the CSV Upload fallback to import your data manually.

The Bid Intelligence tab displays all tracked bids in a sortable table. Each row shows:

Bid Name — the official project or solicitation name.

Client — the entity issuing the bid (government agency, private owner, etc.).

Value — the estimated contract value.

Due Date — the bid submission deadline.

Status — color-coded badges: green for Won, gold for Active, gray for Pending, red for Lost.

Win Probability — an AI-estimated likelihood of winning the bid based on historical data and competitive analysis.

Click any row to open the TLRW Analysis panel, which breaks down the bid using the Think-Learn-Reflect-Write methodology, giving you strategic insight for each phase of your pursuit.

The ROI Calculator helps you quantify the financial impact of using NUVABASE intelligence in your operations.

Inputs:

• Annual Bid Volume — how many bids you submit per year.

• Average Bid Size — the typical contract value you bid on.

• Current Win Rate — your existing win percentage without NUVABASE.

• Estimated Win Rate Improvement — the projected increase from better intelligence (8% is conservative based on client results).

• Annual Operating Costs — your current annual overhead.

• Estimated Efficiency Gain — the projected reduction in waste and overhead.

Results calculate automatically as you adjust any input. The methodology is based on real results, including $7M in savings delivered for Chicago Public Schools. Use the Print button to create a clean PDF for stakeholder presentations.

The Generate Proposal tab creates professional, TLRW-structured proposals ready for printing or PDF export.

Steps:

1. Enter the client name and select the project type from the dropdown.

2. Specify the estimated project value and desired timeline.

3. Describe the key requirements in the text area — include scope, certifications, special conditions, etc.

4. Click "Generate TLRW Proposal" to create the document.

The generated proposal includes: NUVABASE letterhead, executive summary, TLRW methodology breakdown (how each phase applies to the project), deliverables, timeline, investment details, credentials, and a signature block.

Click "Print Proposal" to open the browser print dialog. Use "Save as PDF" in the print dialog to create a PDF version for email distribution.

Dashboard shows DEMO data: This is normal if you haven't connected live API sources. The dashboard is fully functional with demo data for evaluation purposes.

API connection shows DEMO after saving credentials: Verify your API key is correct. The badge updates to LIVE only when valid credentials are stored. In this demo version, any non-empty value will register as LIVE.

CSV upload not working: Ensure your file is a valid .csv format under 10MB. The file should have headers matching the expected fields (bid name, client, value, due date, status).

Print layout looks wrong: Use Chrome or Edge for best print results. Safari and Firefox may render slightly differently. Always use "Save as PDF" rather than direct printing for consistent results.

Settings lost after closing browser: This dashboard stores data in localStorage. Clearing browser data or using incognito/private mode will reset all settings. Use a standard browser session for persistent data.

Glossary of Terms

Key construction and NUVABASE terminology used throughout this dashboard.

Bid Bond
A surety bond submitted with a bid proposal that guarantees the bidder will enter into the contract at the bid price if awarded. Typically 5-10% of the bid amount. Required on most public construction projects to protect the project owner from bid withdrawal.
Change Order
A formal document that modifies the original construction contract. Change orders adjust the scope, cost, or timeline of a project and must be approved by all parties. Tracking change orders is critical for maintaining project profitability.
Compliance Score
A weighted metric calculated by NUVABASE that reflects the current status of all required certifications, licenses, insurance policies, and registrations. A score of 90% or above is considered bid-eligible; below 80% indicates significant risk.
DBE (Disadvantaged Business Enterprise)
A federal certification program for small businesses owned and controlled by socially and economically disadvantaged individuals. Many government contracts include DBE participation requirements, typically ranging from 10-30% of contract value.
General Contractor (GC)
The primary contractor responsible for overall management and coordination of a construction project. The GC holds the prime contract with the project owner and manages all subcontractors, suppliers, and day-to-day operations on the job site.
Liquidated Damages
A pre-determined amount of money specified in the contract that the contractor must pay the owner for each day the project extends beyond the agreed completion date. Amounts typically range from $500 to $10,000+ per day depending on project size.
OSHA (Occupational Safety and Health Administration)
The federal agency responsible for ensuring safe and healthy working conditions. OSHA sets and enforces workplace safety standards. Construction companies must maintain OSHA compliance including safety training records, site safety plans, and incident reporting.
Prevailing Wage
The minimum wage rate that must be paid to workers on public construction projects, as determined by the Department of Labor. Prevailing wage rates vary by trade, location, and project type. Required under the Davis-Bacon Act for federal projects and many state equivalents.
RFP (Request for Proposal)
A formal solicitation document issued by a project owner that invites contractors to submit proposals for a construction project. RFPs typically include project scope, requirements, evaluation criteria, submission deadlines, and contract terms.
SAM.gov
The System for Award Management — the official U.S. government system for entity registration and contract opportunity searching. All businesses must register in SAM.gov to be eligible for federal contracts. Registration must be renewed annually.
Subcontractor
A specialized contractor hired by the general contractor to perform a specific portion of the construction work (e.g., electrical, plumbing, concrete). Subcontractors operate under agreements with the GC rather than directly with the project owner.
Surety Bond
A three-party agreement between the contractor (principal), the project owner (obligee), and the surety company that guarantees the contractor will fulfill contractual obligations. Common types include bid bonds, performance bonds, and payment bonds.
TLRW Framework
The NUVABASE proprietary methodology: Think, Learn, Reflect, Write. A structured approach to construction intelligence where Think = Analysis (strategic assessment), Learn = Data (gathering and processing information), Reflect = Evaluate (risk assessment and decision support), and Write = Proposal (deliverable generation and documentation).
Win Rate
The percentage of submitted bids that result in contract awards. Industry average for construction is typically 15-25%. NUVABASE clients using the TLRW framework have achieved win rates of 30-40% through better bid targeting and intelligence-driven pursuit decisions.
